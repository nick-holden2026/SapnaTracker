Set up Firebase (3 minutes)
  1. Create a free project at console.firebase.google.com.
  2. Build → Authentication → Get started → Sign-in method → Anonymous → Enable.
  3. Build → Realtime Database → Create database (any region, locked mode).
  4. Open the database Rules tab, paste this and Publish:
    {"rules":{"rooms":{"$room":{".read":"auth!=null",".write":"auth!=null"}}}}
  5. Project settings → Your apps → Web (</>) → copy the firebaseConfig and paste below. It must include databaseURL.
  6. On your other device paste the same config and the same room code.
